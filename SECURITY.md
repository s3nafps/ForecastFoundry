# Security policy

Do not open a public issue for a suspected credential, wallet, signing, or
execution vulnerability. Send a private report to the maintainers listed in
the repository hosting service with reproduction steps and affected commits.

Never include private keys, API secrets, unlock passwords, or customer data in
reports. The MCP and dashboard processes must never receive executor keystores.
Default deployments are paper-only; test all live gates against a disposable
account and follow jurisdiction-specific legal review before real execution.
